## Zebkit

Before any Zebkit markup, component, token, variant, utility, CSS, or accessibility work, read `./zebkit/context/skill/SKILL.md`.
The skill orients from this project's build and routes you to the relevant generated reference under `./zebkit/context/llms.txt`.

After token/config changes run `npx zebkit build`. After generating or editing markup, run
`npx zebkit check --format=json` and fix what it reports. Use `zebkit verify` for rendered
behavior, focus, reflow, themes, states, and runtime accessibility.
